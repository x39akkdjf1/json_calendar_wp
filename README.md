# JSON Calendar WordPress Plugin

A small WordPress plugin that fetches calendar entries from a JSON endpoint and renders them in posts and pages.

## Install

1. Copy this repository (or `json-calendar-wp.php`) into `wp-content/plugins/json-calendar-wp/`.
2. Activate **JSON Calendar** in WordPress.
3. Open **Settings → JSON Calendar** and enter the URL of the JSON generated by `json_calendar_generator`.
4. Add `[json_calendar]` to a page or post.

The endpoint may return either a JSON array, an object with an `entries` array, or an object with an `events` array. Entries can use `title`, `name`, or `summary`; `start`, `start_date`, `date`, or `datetime`; `end` or `end_date`; `description`; `location`; and `url`/`link`/`permalink`.

## Shortcode options

Use a different endpoint or limit the number of entries for a specific page:

`[json_calendar url="https://example.com/calendar.json" limit="10"]`

Responses are cached for 15 minutes using the WordPress transient API.
